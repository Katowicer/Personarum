# Personarum

Applicazione web client/server per la gestione centralizzata di profili personali e documenti compilabili

## Tecnologie

### Backend

- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- PostgreSQL
- Flyway
- OpenAPI / Swagger
- JUnit 5
- Mockito
- JaCoCo

### Frontend

- Vue 3
- TypeScript
- Vuetify
- Pinia
- Vue Router
- Vite

### Ambiente

- Devbox
- direnv
- Docker

## Esecuzione

La configurazione locale è contenuta nel file `.env`.

Credenziali utenze

| Ruolo | Username | Password |
| --- | --- | --- |
| ADMIN | `admin` | `ADMIN_PASSWORD_007` |
| OPERATOR | `operator` | `OPERATOR_PASSWORD_007` |

Frontend in locale: [http://localhost:5173](http://localhost:5173)

Frontend docker: [http://localhost:8081](http://localhost:8081)

Backend in locale: [http://localhost:8080](http://localhost:8080)

Backend docker: [http://localhost:8080](http://localhost:8080)

Swagger UI: [http://localhost:8080/swagger-ui/index.html](http://localhost:8080/swagger-ui/index.html)

Specifica OpenAPI: [http://localhost:8080/v3/api-docs](http://localhost:8080/v3/api-docs)
